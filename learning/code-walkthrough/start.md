# start.sh — ソース全文と逐次解説

**原本:** `scripts/start.sh`

## 1. ファイル概要

- **役割:** WSL/LinuxのシェルからプロジェクトルートでPHP組み込みサーバーを開始します。
- **入力と出力:** 入力: bash実行。出力: 127.0.0.1:8000で稼働する開発サーバープロセス。
- **主要メソッド・処理:** cd、dirname、exec、php -S
- **前提知識:** bash、カレントディレクトリ、実行権限
- **他ファイルとの関係:** 詳細は `learning/01_ARCHITECTURE.md` の依存図を参照してください。

## 2. ソースコード全文

> このブロックは実装ファイルとバイト内容（末尾改行を除く）が一致しています。変更した場合は逐次解説も再生成・更新してください。

```bash
#!/usr/bin/env bash
set -euo pipefail
cd "$(dirname "$0")/.."
exec php -S 127.0.0.1:8000 -t .
```

## 3. 行・コードブロック単位の逐次解説

- **L1** `#!/usr/bin/env bash` — このスクリプトをbashで実行する指定です。
- **L2** `set -euo pipefail` — コマンド失敗、未定義変数、パイプ失敗を検出しやすくします。
- **L3** `cd "$(dirname "$0")/.."` — 起動位置に依存せずプロジェクトのルートへ移動します。
- **L4** `exec php -S 127.0.0.1:8000 -t .` — シェルをPHPサーバープロセスで置き換え、ローカルに待ち受けます。

## 4. 実行トレース（値と呼び出し順）

`bash scripts/start.sh` を実行 → スクリプトのあるディレクトリの1階層上へ `cd` → `exec php -S 127.0.0.1:8000 -t .` が開発サーバーを開始 → Ctrl+Cで停止します。
